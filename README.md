# React + Vite

⏱ Stopwatch App (React + Vite)

A simple and interactive Stopwatch application built using React and Vite.

✨ Features

Start, Stop, and Reset functionality

Millisecond precision timer

Clean and responsive user interface

Built with modern React + Vite setup

🚀 Getting Started
1. Clone the repository
git clone https://github.com/your-username/stopwatch-react-vite.git

2. Navigate to the project folder
cd stopwatch-react-vite

3. Install dependencies
npm install

4. Run the development server
npm run dev

5. Build for production
npm run build

🛠️ Tech Stack

React 18

Vite
